# GATE 2027 Biotechnology — Syllabus Tracker

Based on the GATE 2027 Biotechnology syllabus supplied in the chat.

- 6 sections
- 170 individually trackable checklist items (compound syllabus statements split into useful checklist units)
- Search, All/Pending/Completed filters
- Expand/Collapse all
- Section and overall progress
- localStorage persistence
- PWA manifest and offline service worker
- No backend/login/dependencies

Keep all three application files in the same folder. For PWA installation, serve them over HTTPS or localhost.
